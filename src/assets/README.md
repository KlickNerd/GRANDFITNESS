# Images

Drop the real photos into this folder using these exact filenames:

| File | Used on | Content |
|---|---|---|
| `hero.jpg` | Homepage hero | Gym hero shot (portrait, ~4:5) |
| `gym-interior.jpg` | Homepage + About | Gym interior / quote wall |
| `team.jpg` | About | Team group photo (wide, ~21:9) |
| `og-cover.jpg` | Social sharing preview | 1200x630px branded image |
| `favicon.png` | Browser tab | 64x64px logo |
| `coaches/gurgen.jpg` … `coaches/joni.jpg` | Coach cards + profiles | Portrait photos (~3:4), one per coach: gurgen, mariam, otar, goga, nika, rezo, ninutsa, joni |
| `space/training-floor.jpg`, `space/cardio-zone.jpg`, `space/free-weights.jpg` | About | Facility photos (16:11) |

Missing images hide themselves automatically (styled placeholder shows instead), so the site works before all photos are in place. Recommended: JPG, max ~1600px wide, compressed (e.g. squoosh.app).
